Security Architecture

Bank-grade cryptographic guarantees.

✓

Hardware Enclave Attestation

Verifies device trust signatures using Android KeyStore or Apple Secure Enclave certificates.

✓

Monotonic Nonce Deduplication

Authoritative Redis & PostgreSQL unique nonce registry eliminates double spending and replay attacks.

✓

ECIES-AES-256-GCM Confidentiality

Envelope contents are invisible to untrusted relay nodes. Only settlement authority can decrypt payloads.

Transactional Outbox Pattern

Prevents state disparity by committing outbox business events in the same DB transaction as ledger writes.
